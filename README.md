# BrainBloom

## 概要

マインドマップアプリ(Tauri + React + Vite)

## 利用ライブラリ

[MindElixir](https://github.com/SSShooter/mind-elixir-core/tree/master)を利用しています。

## 開発

前提: Node.js、Rust ツールチェイン、[Tauri の前提環境](https://v2.tauri.app/start/prerequisites/)(Windows は WebView2 と MSVC Build Tools)

```bash
npm install
npm run tauri:dev     # 開発起動
npm run tauri:build   # インストーラ作成
```
